  • 스테이지는 position: fixed; inset: 0
  • 모든 슬라이드는 absolute로 같은 자리에 겹칩니다
  • 안 보이는 슬라이드는 visibility: hidden + inert
모든 페이지가 같은 자리에 겹쳐 있어서 fade나 zoom처럼 두 장이 겹치는 전환이 자연스럽게 됩니다. display: none을 쓰지 않는 이유는 전환 애니메이션이 동작하지 않기 때문입니다.

Transitions · Web Animations API

전환 효과 3종

fade

opacity만 바꿉니다. 가장 무난한 기본값입니다.

slide

방향을 인식합니다. 뒤로 가면 반대쪽으로 밀립니다.

zoom

scale과 opacity를 함께 씁니다. 이 슬라이드가 zoom으로 들어왔습니다.

이 슬라이드에는 data-transition="zoom"이 지정되어 있습니다. 덱 기본값은 slide입니다. 전환 중에 키를 여러 번 눌러도 다음 한 페이지만 예약됩니다. Esc를 누르면 진행 중인 전환을 바로 끝냅니다.

Code line highlight

코드의 특정 줄 강조


async function goTo(c, { from = 'local' } = {}) {
  c = clamp(c, 0, slides.length - 1);
  if (animating) { pending = { cur: c, from }; return; }
  if (c === state.cur) return;

  const prev = state.cur;
  state.cur = c;
  updateUI();
  if (from !== 'hash') writeHash();
  if (from !== 'remote') send({ type: 'go', cur: c });

  await transition(prev, c);
  playSteps(c, c > prev ? 1 : -1);
}

범위를 맞추고, 전환 중이면 다음 한 장만 예약하고, 같은 페이지면 무시합니다

상태를 바꾸고 화면·해시·다른 창을 갱신합니다

전환이 끝나면 그 페이지의 빌드 효과를 자동 재생합니다

data-lines="|2-4|6-10|12-13" 한 줄로 단계별 강조를 지정합니다. 첫 단계(빈 값)는 강조 없음입니다. 코드 강조와 아래 설명이 같은 data-step 번호를 공유해서 함께 바뀝니다.

Accessibility · Performance

빠르고, 누구나 쓸 수 있게

  • transform과 opacity만 애니메이션합니다
  • will-change는 전환 중인 두 장에만 잠깐 켭니다
  • 숨은 슬라이드는 inert로 포커스와 스크린리더에서 뺍니다
  • 페이지가 바뀌면 aria-live로 "슬라이드 8 / 10"을 읽어 줍니다
  • 동작 줄이기 설정이면 짧은 fade로 바꾸고 빌드 효과를 한 번에 보여줍니다
transform과 opacity는 레이아웃을 다시 계산하지 않고 GPU 합성만으로 처리되어 부드럽습니다. will-change를 모든 슬라이드에 계속 켜 두면 메모리를 많이 쓰므로 전환 중에만 씁니다.
