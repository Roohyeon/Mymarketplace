01 · Agentic Loop & Harness

생각은 모델이, 실행은 Harness가

Claude Model

Thinking

  • 요청 이해 · 추론
  • 계획 세우기
  • 다음 행동 결정

Harness

Action

  • 터미널 명령 실행
  • 파일 읽기 · 쓰기
  • 도구 호출 처리
첫 번째는 Agentic Loop와 Harness 구조입니다. Claude AI 모델은 추론(Thinking)을 담당하고, Harness는 터미널/파일 읽기 등의 실행(Action)을 담당하는 구조입니다.

01 · Agentic Loop

3단계 루프를
목표 달성까지 반복

  1. 1
    모델 추론지금 상황에서 무엇을 할지 결정
  2. 2
    Tool 실행Harness가 실제 명령·파일 작업 수행
  3. 3
    결과 피드백실행 결과를 다시 모델에게 전달

탈출 조건 — 더 이상 도구가 필요 없으면 최종 답변

이 동작은 1. 모델 추론, 2. Tool 실행, 3. 결과 피드백 — 3단계 루프를 계속 반복하면서 사용자의 목표를 달성해 나갑니다.

에이전트가 스스로 기록

CLAUDE.md
# 프로젝트 지침 ## 명령어 - 테스트: npm test - 린트: npm run lint ## 규칙 - 커밋 메시지는 한국어로 - src/legacy 는 수정 금지 <!-- 사람이 읽고 고칠 수 있는 기억 -->
세션이 끝나도 지침을 유지하기 위해 프로젝트 루트의 CLAUDE.md와 Auto Memory를 활용해 투명한 기억장치를 만듭니다.

03 · Safety & Permission

7가지 권한 모드로 자율 범위를 통제

◀ 통제자율 ▶
plan읽고 계획만,
수정은 하지 않음
default위험할 수 있는 작업은
매번 확인
acceptEdits파일 수정은
자동 승인
bypassPermissions확인 없이 실행
격리 환경 전용

상황에 맞게 에이전트에게 맡길 범위를 고릅니다.

세 번째는 안전/권한 프레임워크입니다. plan, default, bypassPermissions 등 7가지 모드로 에이전트의 자율 동작 범위를 통제합니다. (화면에는 대표 모드 4개만 표시)
